# 今天吃什么 · 摇一摇

一个给手机用的小页面：两个独立板块 + 老虎机，帮你在「今天吃什么」这件事上少纠结五分钟。

## 功能

- **日常餐食（24 个）**：番茄炒蛋、饺子、炒粉、蛋炒饭、牛肉面、麻辣烫、黄焖鸡、煲仔饭、烧烤、火锅、螺蛳粉、兰州拉面，以及青椒肉丝、鱼香肉丝、宫保鸡丁、回锅肉、麻婆豆腐、酸辣土豆丝、蒜蓉西兰花、手撕包菜、干煸四季豆、红烧肉、清蒸鲈鱼、可乐鸡翅
- **调理食谱（18 个）**：红枣桂圆小米粥、菠菜猪肝汤、当归生姜羊肉汤、山药南瓜粥、黑芝麻核桃糊、姜枣茶、番茄牛腩、红豆花生汤、小米南瓜蒸蛋、桂圆红枣鸡蛋糖水，以及五红汤、黄芪党参乌鸡汤、猪肚鸡汤、牛肉萝卜汤、桂圆莲子银耳羹、桑葚黑芝麻粥、酒酿蛋、陈皮生姜水
- 两个板块用顶部按钮独立切换，各自有独立的老虎机池
- 点「摇一摇」三格转轮滚动，停在哪格就吃哪个，并展开食材和做法
- 也可以直接点下面的菜品卡片查看详情
- 纯静态单文件，无外部依赖，微信内打开不会跳浏览器

## 本地打开

直接双击 `index.html`，或者：

```bash
python -m http.server 8080
# 打开 http://127.0.0.1:8080
```
